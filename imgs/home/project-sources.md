# Capturas de los proyectos

Capturas de las interfaces publicadas, recortadas para los proyectos y guardadas en WebP para que las galerías funcionen sin descargar imágenes de otros dominios. Las de Animales Fantásticos se tomaron el 25 de octubre de 2026; las demás, el 24 de octubre de 2026.

Las capturas iniciales de Don Quijote, Animales Fantásticos y Bikcraft tienen variantes de 480, 672 y 800 px. Las otras capturas solo se descargan al abrirlas con los controles (sin JavaScript se muestra la inicial).

- `proyecto-donquijote-{portada,carta,horarios}.webp`: https://donquijotechuy.com/ — sitio del restaurante. Su pie acredita el diseño y desarrollo a @davotech.uy.
- `proyecto-animalesfantasticos-{portada,leon,curiosidades}.webp`: https://davooojkk.github.io/animalesfantasticos/ — ejercicio del curso de JavaScript de [Origamid](https://www.origamid.com/curso/javascript-completo-es6), con fichas de animales y preguntas interactivas. Las capturas locales muestran el águila, el león y una curiosidad desplegada.
- `proyecto-bikcraft-{portada,catalogo,producto}.webp`: https://davooojkk.github.io/bikcraft_aula/ — ejercicio del curso de HTML y CSS de [Origamid](https://www.origamid.com/curso/html-e-css-para-iniciantes); no se presenta como encargo de un cliente ni se atribuye el diseño original al autor del portfolio.

Los tres archivos originales `proyecto-barbero.jpg`, `proyecto-hamburgueseria.jpg` y `proyecto-oculista.jpg` se conservan en el repositorio, pero ya no se muestran en las galerías.

Las capturas `proyecto-dollivera-{formulario,registros,adaptable}.webp` se conservan como material de la versión anterior del portfolio, pero tampoco se cargan en la web. En `registros` hay únicamente gastos de ejemplo, no datos de usuarios.
